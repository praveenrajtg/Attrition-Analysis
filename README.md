# Employee Attrition Analysis – Power BI Project

Project Overview

This Power BI project presents an in-depth analysis of employee attrition within an organization. The goal is to identify the key factors contributing to attrition and provide data-driven insights that can help HR and management improve employee retention.

Key Features

- **Interactive Dashboard:** Visualizes trends in employee attrition by department, age, education, job satisfaction, and more.
- **KPI Indicators:** Highlights critical metrics such as attrition rate, average working years, job level, and employee satisfaction scores.
- **Filters and Slicers:** Enables users to drill down by job roles, education levels, marital status, and other categories.
- **Data Insights:** Reveals patterns and correlations using visuals such as bar charts, pie charts, line graphs, and heat maps.

## Tools & Technologies Used

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query Editor
- Data Modeling & Relationships

## Objectives

- Understand the demographics and job profiles most prone to attrition.
- Identify correlations between attrition and factors like work-life balance, job satisfaction, and income.
- Present insights through visually appealing and interactive dashboards.
